# Lint report — reference format (from the writer, 2026-11-13)

The writer's own lint rules (their buckets TELL / AGE / BODY / CONTINUITY were for one project; Storyloom uses
its own buckets but keeps the rest):

- Quote the line and give its line number. No paraphrasing.
- One finding per line. Mark it `hard` if it contradicts canon, `soft` if taste.
- Measure, don't rewrite. Do not propose replacement sentences except in one short clause.
- A clean bucket says clean. Do not pad.
- Nothing in the chapters or canon changes.

Report: counts first — `BUCKET n / BUCKET n / …, hard n` — then the findings grouped by bucket, then the chapter
word count, then one line: the single biggest problem in the chapter.
